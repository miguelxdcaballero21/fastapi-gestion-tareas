# FastAPI Gestión de Tareas

API REST desarrollada con FastAPI y SQLModel para la gestión de usuarios, tareas y actividades.

## Tecnologías utilizadas

- Python 3
- FastAPI
- SQLModel
- SQLAlchemy
- SQLite
- Uvicorn

## Funcionalidades

### Usuarios
- Crear usuario
- Listar usuarios
- Consultar usuario por ID
- Actualizar usuario
- Eliminar usuario

### Tareas
- Crear tarea
- Listar tareas
- Consultar tarea por ID
- Actualizar tarea
- Eliminar tarea

### Actividades
- Crear actividad
- Listar actividades
- Consultar actividad por ID
- Actualizar actividad
- Eliminar actividad
